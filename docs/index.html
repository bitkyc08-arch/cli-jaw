Infrastructure

What you get

Not a chatbot wrapper. A full-stack assistant with real infrastructure.

Manager dashboard

Track local instances, preview live Web UIs, switch themes, inspect runtime settings, and manage employees from one browser workspace.

PABCD orchestration

DB-persisted 5-phase FSM: Plan, Audit, Build, Check, Done. Workers are read-only. You approve every phase.

3-layer memory

History Block (session context) + Memory Flush (episodes, daily logs) + Soul and Task Snapshot (identity, semantic recall). SQLite FTS5 search.

Employee system

Dispatch specialist agents: Frontend, Backend, Research, Docs, each with its own CLI and model. Boss orchestrates, workers verify.

Notes workspace

Dashboard-local markdown vault with folders, rename and move, dirty markers, split preview, KaTeX, Mermaid, and highlighted code blocks.

Browser automation

Chrome CDP, vision-click, DOM reference for ChatGPT/Grok/Gemini, Computer Use via Codex App, and a diagram skill for interactive visualizations.

Kanban board

Drag-and-drop task tracking built into the dashboard. Columns, card creation, and reordering per home, with zero setup.

200+ reference skills

Office docs (PDF, DOCX, XLSX, PPTX, HWP), GitHub, Notion, image generation, video rendering, and Telegram media, activated from the reference catalog as needed.

Telegram + Discord

Chat from your phone. Voice messages with multi-provider STT. Files, photos, slash commands, and scheduled task results.

MCP: install once

Install MCP tools once and sync supported MCP-aware engines. Grok CLI runs as a standard runtime without claiming MCP sync.

7+ surfaces

Root CLI, terminal TUI, Web PWA, Electron desktop, Manager dashboard, Telegram, and Discord. Web/TUI live updates use the SSE-first GET /api/events channel with legacy WebSocket fallback only for older servers. Desktop releases bundle a Node.js sidecar so the app and terminal shim can run without a global npm install.

Heartbeat system

Cron and interval jobs that run while you sleep. Morning check-ins, recurring reports, and scheduled tasks, with results forwarded to your channel.

Orchestration

PABCD: AI That Plans Before It Builds

A DB-persisted finite state machine that enforces planning, auditing, and verification. No cowboy coding: every phase requires your approval.

PPlan AAudit BBuild CCheck DDone
orchestration.log
09:41:02$ jaw orchestrate
09:41:03P → Plan diff-level implementation plan; waiting for approval
09:42:18A → Audit read-only worker verifies feasibility
09:43:11B → Build boss implements + worker verifies
09:47:46C → Check type-check, docs, consistency
09:48:09D → Done summary written; returned to idle

Workers are read-only

Audit and verification workers cannot modify files. They inspect, report, and recommend, but never touch your code.

Hard stop at every phase

The AI cannot self-advance. You review and approve each transition. No runaway agents, no surprise changes.

DB-persisted state

State survives server restarts. CLI and Web UI share the same FSM, so you can resume from any interface.

Parallel-safe dispatch

Independent subtasks run concurrently via Promise.all with automatic file-overlap detection and sequential fallback.

New to the terminal? One-click install

macOS: step by step

Step 1: Open Terminal

Open Finder → Applications → Utilities → Terminal.app
(or press ⌘ Space and type Terminal)

Step 2: Paste and hit Enter

curl -fsSL https://raw.githubusercontent.com/lidge-jun/cli-jaw/main/scripts/install.sh | bash

This installs Node.js + CLI-JAW automatically. Wait until it finishes.

Step 3: Login and Launch

# pick any one
copilot login
claude auth login
codex login
gemini login

jaw dashboard

Open http://localhost:24576 for the manager dashboard. Agent chat UI stays on http://localhost:3457 when you run jaw serve.
