技能目录

CLI-JAW 提供活跃运行时技能和 200+ 参考技能。本页面是 GitHub Pages 上发布的代表性目录；实际可用技能请以 jaw skill list 和 skills_ref/ 为准。

自然语言："스킬 목록 보여줘"、"cloudflare 스킬 설치해줘"、"프론트엔드 스킬 켜줘"——这些都可以在聊天中直接使用。也可以使用斜杠命令 /skill list。

快捷命令

jaw skill list
显示所有激活和参考技能及其状态
jaw skill install <name>
激活一个参考技能（复制到激活目录）
jaw skill remove <name>
停用一个技能（移回参考目录）
jaw skill info <name>
显示技能描述、触发条件和文件路径
jaw skill reset
将所有技能重置为默认的 25 个
/skill list
聊天内斜杠命令：显示技能统计

技能工作原理

每个技能都是一个包含 SKILL.md 文件的目录。激活的技能通过 getSystemPrompt() 注入到智能体的系统提示词中。参考技能出现在"可用技能"列表中，智能体知道它们的存在，但在激活之前不会加载其内容。

# Active skills directory
~/.cli-jaw/skills/
  dev/SKILL.md
  browser/SKILL.md
  memory/SKILL.md
  ...

# Reference skills directory
~/.cli-jaw/skills_ref/
  registry.json
  cloudflare/SKILL.md
  docker/SKILL.md
  ...

员工提示词（getEmployeePromptV2()）会自动注入角色特定和阶段特定的技能。例如，"Frontend"员工会获得 dev-frontend；在 Check 阶段，员工会获得 dev-testing。

安装和管理技能

安装参考技能

# Install a single skill
jaw skill install cloudflare

# Install multiple skills at once
jaw skill install docker kubernetes terraform

# Install all skills in a category
jaw skill install --category "Cloud & Deploy"
聊天内操作："cloudflare 스킬 설치해줘" 或 "Docker랑 Kubernetes 스킬 켜줘"——智能体会为你执行安装命令。

移除技能

# Remove a skill (moves back to reference)
jaw skill remove cloudflare

# Remove multiple
jaw skill remove docker kubernetes

查看技能信息

# Detailed info about a skill
jaw skill info dev-frontend

# Output:
#   Name:     dev-frontend
#   Status:   active
#   Category: Development
#   Path:     ~/.cli-jaw/skills/dev-frontend/SKILL.md
#   Size:     4.2 KB
#   Lines:    127

重置为默认

# Reset all skills to the 25 defaults
jaw skill reset

# Force reset (no confirmation prompt)
jaw skill reset --force
警告：jaw skill reset 将停用所有自定义技能并恢复默认的 25 个。你的自定义技能文件会保留在 ~/.cli-jaw/skills_ref/ 中。

创建自定义技能

通过创建技能目录来添加自己的领域知识：

mkdir -p ~/.cli-jaw/skills/my-company
cat > ~/.cli-jaw/skills/my-company/SKILL.md << 'EOF'
# My Company Standards

Internal coding standards and domain knowledge.

## When to Use

Trigger when working on any project in ~/work/ directory.

## Rules

1. Use pnpm instead of npm.
2. All APIs must follow our internal OpenAPI spec.
3. Database migrations use Drizzle ORM.

## Templates

```typescript
// Standard API response format
interface ApiResponse<T> {
  success: boolean;
  data: T;
  error?: string;
  timestamp: string;
}
```
EOF
聊天内操作："회사 코딩 표준 스킬 만들어줘"——智能体可以根据自然语言描述为你搭建自定义技能。

技能文件结构

每个技能是一个目录，至少包含一个 SKILL.md 文件。复杂的技能可能包含参考子目录：

~/.cli-jaw/skills/dev-frontend/
  SKILL.md              # Main skill prompt (injected into system prompt)
  references/
    react.md            # Deep guidance for React
    vue.md              # Deep guidance for Vue
    svelte.md           # Deep guidance for Svelte
    tailwind.md         # Tailwind-specific rules

SKILL.md 充当编排器。它包含高层规则，并在需要更深层上下文时引用子文件。
